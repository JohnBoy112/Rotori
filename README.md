
# Rotori Privacy Policy

Last Updated: May 31, 2026

Rotori does not collect, store, transmit, sell, or share any personal information.

The extension only analyzes Roblox trade information that is already visible on Roblox trade pages. All calculations are performed locally within the user's browser.

Rotori may use Chrome's storage permission to save user preferences and extension settings on the user's device. This data is not transmitted to any external server.

Rotori does not:
- Collect personal information
- Track users across websites
- Sell user data
- Share user data with third parties
- Use remote code
